SQL � Structured Query Language
-----------------------------------------------------------
A database stores data in the form of tables which contains rows & columns. 
A query is a command that we write to communicate with the database and follow syntax 

Relational Db � In this we store data in tables, which has rows & columns, easy to store and flexible.
Data is stored in a structured way that organizes data into tables, Tables -> Relations
Ex : MySQL, Postgres, Oracle

Non-Relational DB - In this we store unstructured data in the form of document, graphs, non-tabular format, Key-value pairs

SQL Functions :
This functions help us analyze, transform, or summarize data in our tables.
1) Aggregate Functions :   
(1) COUNT() ->  returns the total number of respective field
SELECT COUNT(*) from USERS; -> 679
SELECT COUNT(*) from USERS where gender = �male� -> 67
(2) MAX() & MIN() � returns the min and max of the respective field.
SELECT MIN(salary) AS min_salary, MAX(salary) AS max_salary from USERS;
(3) AVG() -> Average of the specific field
SELECT AVG(SALARY) AS avg_salary FROM users;
(4) SUM() -> sum of the respective field
SELECT SUM(SALARY) AS total_salary_female FROM users where gender= �female�;
SELECT gender, AVG(SALARY) as avg_sal FROM users GROUP BY gender;
2) STRING functions() 
(1) LENGTH() -> length of the string
SELECT name, LENGTH(name) AS name_length FROM users;
(2) LOWER () -> in lower case
SELECT id,gender, LOWER(name) AS name  FROM users;
(3) CONCAT -> adding 2 strings
SELECT name, LENGTH(name), gender, CONCAT(LOWER(name), �_Rai�) AS name_length FROM users;
3) TIME Functions()  
(1) NOW() � returns the current time
SELECT LOWER(name) as name, now() as time from users;
(2) YEAR() -returns the yeat
SELECT name, YEAR(date_of_birth) as year_of_birth from users;
(3) DAY() � retuns the date
SELECT name, DAY(date_of_birth) as year_of_birth, DAY(NOW()) AS today from users;
(4) MONTH() � returns the  month
SELECT name, MONTH(date_of_birth) as year_of_birth, MONTH(NOW()) AS today from users
(5) DATEDIFF() � returns the all days from the current day to birth day
SELECT name, DATEDIFF(CURDATE(), date_of_birth) as total_days from users
(6) CURRDATE() � return sthe current day
4) Mathematical Functions()
         1. ROUND()  2. FLOOR 3. CEIL - > when dealing with decimals

11) GROUP BY and HAVING :
The GROUP BY clause is used to group rows  that have the same values in specified column. 
typically used by AGGREGATE functions like, sum, ag, min, max

example : 

SELECT gender, avg(salary) AS avg_salary FROM users GROUP BY gender ;

HAVING  -> It works like  where clause but it should be used after GROUP BY clause. Where cannot be used after GROUP by clause.

SELECT gender, avg(salary) AS avg_salary, COUNT(*) FROM users  GROUP BY gender  having  AVG(salary)< 66000;
